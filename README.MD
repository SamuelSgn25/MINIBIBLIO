The goal of this project is to create a web application like a digital bibliothèque by creating and managing books and members. FOr this project, I choose to use :
React Js for the interface, Node Js(Express) for the backend server and PostGreSql for managing the database.

# Backend Setup :
cd backend
npm install (for installing dependecies)
Créez votre fichier .env sur la base du .env.example
npm start or node index.js

# Frontend Setup
cd frontend
npm install
npm run dev
